# CodexMonitor

Windows 11 的 Codex 额度与重置时间监控工具。当前开发分支已改为 **C++20 + Win32 + DirectWrite / Direct2D**，界面和数据层均为原生实现。

> 当前为本地原生预览版 `2.0.0-native-preview.3`，尚未发布 GitHub Release。公开最新版仍为旧架构的 v1.0.6；v1.0.7 已撤回。保留任务栏窗口所有权方案，新增任务视图及同类面板造成任务栏遮挡时的针对性层级恢复；其他 Windows 版本仍需验证。

## 运行

- Windows 11 x64；使用已登录订阅账户的 Codex CLI 或 Codex 桌面版提供的 CLI。
- 原生版只分发一个 `CodexMonitor.exe`，无需安装 .NET、Windows App SDK 或 VC++ 运行库，无运行库解压步骤。
- 双击 EXE 后显示任务栏数字条和托盘图标。单击或双击数字条、托盘图标均打开详情；右键打开操作菜单。
- 再次启动会激活现有实例的详情。原生版与旧版使用相同的单实例锁，请先退出旧版再启动原生版。
- 主程序目录不写入配置或缓存；Windows 自行维护的系统记录及 Codex 自身的文件不属于本程序管理范围。

## 迁移功能

- 两行数字条：剩余额度与自然重置倒计时；5 小时额度优先，耗尽时仍显示 0%。字段暂缺不会误判为该额度不存在。
- 透明任务栏背景、两侧边线、统一蓝色“周 / 5h”标签和正常状态点、悬停梭形柔光、原有 Q 图标。
- 自动、任务栏优先、固定上移模式；任意横向位置拖入任务栏达到 8 DIP 重叠深度即显示蓝色吸附提示，松手后落入最近的安全空位，保存相对偏移；全屏隐藏、任务栏变化检查、Explorer 重建通知。
- 任务视图等入口重排任务栏时，检查实际遮挡者，仅对任务栏覆盖数字条的情况恢复层级；保留位置和焦点，合并重复系统事件。系统宿主进程名大小写不影响全屏判断。
- 紧凑详情窗口，弹出时下缘贴任务栏上缘；系统 Acrylic、统一自绘标题栏、10 DIP 进度条及首次数据加载动画。
- 分别显示 5 小时重置和周额度重置，读条颜色不同；无 5 小时额度时使用等宽纵向布局，仅保留不可用提示。
- 人类可读日期、本地／UTC 切换、完整时间复制，日期与卡片悬停完整时间。
- 重置卡数量与明细独立处理；仅返回数量时保留同账户、同数量的上次明细并标明来源时间；数量变化或明确空列表时清除旧明细。保留相同到期时间的多张卡；可用卡显示“某时间前可用”。
- 四套预设、自定义颜色、跟随系统／浅色／深色、浓度、字号、位置、颜色对比度提示及实时预览。
- 设置窗口与右键菜单同步；开机启动和清除缓存仅保留右键入口。取消设置恢复未保存预览，不撤销已经通过右键菜单保存的选择。
- 后台默认 **1 分钟**刷新，可设 0.5–60 分钟；手动刷新、打开详情、唤醒及网络接口变化触发查询，相邻请求合并，失败退避。
- 详情与设置按需创建，关闭后释放绘制目标与控件；最小化停止动画、释放绘制目标；数字条文字变化才重新测量。

输入框、下拉框和按钮采用 Win32 原生控件。磨砂浓度、字号、水平偏移、上移距离和刷新间隔提供拖动滑条及同步数值框；外观即时预览，刷新间隔保存后生效。雾白采用银白雾蓝、暖砂采用米砂琥珀、石墨采用中性灰银、午夜采用深蓝月光，浅深两种模式均提高了表面明度。

## 缓存、配置与开机启动

| 项目 | 旧版 .NET / WinUI | 原生版 |
| --- | --- | --- |
| 依赖缓存 | `%TEMP%\.net\<EXE名称>\<版本哈希>\`，或自定义解压根目录 | **不再产生** |
| 配置 | `%LOCALAPPDATA%\CodexQuotaMonitor\settings.json` | **同一路径和 JSON 字段格式，直接兼容** |
| 额度数据 | 内存快照 | 仍只在内存，退出后释放 |
| 异常诊断 | 同目录 `ui-failure.json` | 仅出错时写 `native-failure.json`；不记录账户原始响应 |
| 清除缓存 | 使用中的依赖可能需退出后由 PowerShell 清理 | C++ 直接清理本程序诊断和带所有权标记的旧版依赖缓存；无需清理辅助进程 |
| 开机启动 | 当前用户 Run 注册表项 | **相同键、相同开关；指向原生 EXE** |

开机启动位置：`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，值名 `CodexQuotaMonitor`，命令为 `"实际EXE路径" --background`。不创建服务、计划任务或启动目录快捷方式。已有启动项启用时，正常启动原生版会更新到当前 EXE 路径；移动程序后运行一次可更新路径。

清理保留 `settings.json`、启动项及 Codex 登录信息，仅处理本程序拥有的文件，拒绝遍历符号链接／目录联接。旧版仍在运行且占用依赖时，会提示稍后重试。清理范围包括默认 `.net` 目录及当前 `DOTNET_BUNDLE_EXTRACT_BASE_DIR`；以前使用但目前未设置的自定义目录仍需手动处理。不会清理 Windows 字体、图标等系统缓存或 Codex 自己的缓存。

详情见 [原生迁移说明](docs/native-migration.md)。

## 数据与进程

程序通过现有 Codex CLI 的只读 `app-server` 接口初始化、查询账户和额度，复用 Codex 登录机制，不读取或复制认证文件、不兑换重置卡、不创建模型任务。

每次查询使用短生命周期子进程。标准输出有大小上限，错误输出丢弃，查询有超时；使用独立 Job Object 管理自己启动的进程，退出时清理。界面进程降内存不代表 Codex CLI 查询进程的峰值也会下降。

## 构建与打包

开发依赖：Visual Studio 2022 Build Tools 的 C++ x64 工具、Windows 11 SDK、CMake。生产 EXE 使用静态 MSVC 运行库 `/MT`，图标与许可证内嵌。

```powershell
# 编译原生应用（不自动运行测试）
.\scripts\Build.ps1

# 只生成一个 EXE；目标目录必须为空
.\scripts\Publish.ps1 -OutputDirectory .\publish\native

# 启动原生版
.\scripts\Run.ps1

# 显式运行核心回归检查
.\scripts\Test.ps1

# 显式运行原生窗口、真实查询和生命周期检查
.\scripts\Verify-Native.ps1 -ReportPath .\.artifacts\native-runtime-new.json
```

源代码入口：`native/src/main.cpp`。原生构建不使用旧 C# 源码或旧版测试程序；旧实现留作迁移对照，可用 `Build.ps1 -Legacy`、`Test.ps1 -Legacy` 构建检查。旧版发布须指定独立空目录和 `Publish.ps1 -Legacy`。

## 已知边界

- 数字条仍是独立的 Win32 弹出窗口，**没有系统原生独占槽位**。吸附时设置任务栏为 owner，悬浮时解除。不注入 Explorer，不启用 UIAccess。不同 Windows 版本及层级切换动画仍需验证，参见 [遮挡调查](docs/taskbar-system-panel-investigation.md)。
- 系统 Acrylic 依赖 Windows 版本和透明效果设置；不可用或高对比模式时采用实色回退。
- 当前本机缩放为 175%。100%／125%、Explorer 重启、睡眠恢复等场景仍需进一步交互验收，不能以编译通过替代。
- 原生预览版尚未代码签名、未发布远端 Release。

第三方代码：固定版本 JSON for Modern C++ 3.12.0，许可证与哈希见 [第三方声明](THIRD-PARTY-NOTICES.md)。
