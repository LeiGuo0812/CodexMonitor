# CodexMonitor v1.0.0

Windows 11 x64 的 Codex 额度监控工具，单 EXE、自包含、免安装。

## 下载

下载 `CodexMonitor-v1.0.0-win-x64.exe` 后双击运行。`SHA256SUMS.txt` 用于核对文件完整性，无需放在 EXE 旁边。需要本机已登录的 Codex CLI 或 Codex 桌面版。

## 功能

- 任务栏两行额度与重置倒计时，透明背景、彩色标签、柔光梭形悬停边缘和简洁 Q 托盘图标。
- 双击文字或图标打开紧凑磨砂详情，窗口贴合任务栏上缘；支持右键、拖出和拖回任务栏。
- 独立展示 5 小时与周额度重置；5 小时不可用时显示紧凑提示。显示重置卡数量、逐卡截止时间、可读日期和不同颜色的时间进度条。
- 四套详情主题、自定义细节、实时预览、单实例、后台刷新。
- 开机启动开关在“外观与位置 → 启动与维护”，保存后生效，启动路径指向下载的 EXE。
- “清除缓存”与“退出”独立。清理时继续运行，当前占用的运行库在正常退出后清理，保留设置与 Codex 登录信息。

## 文件存放

- EXE 所在目录不释放附加文件。
- 默认运行库缓存：`%TEMP%\.net\<EXE名称>\<版本哈希>\`。
- 设置：`%LOCALAPPDATA%\CodexQuotaMonitor\settings.json`。
- 清理仅针对本程序带所有权标记的运行库缓存及异常日志；再次运行时会重新生成必要缓存。

- 76 项自动化测试通过；Release 构建无警告、无错误。
- 本机 Windows 11 真实额度与重置卡读取、72 次主题/细节修改、详情布局、悬停状态、托盘注册、启动项开关与缓存清理自检通过。
- 实测单 EXE 改名启动、运行目录无附加文件、退出后解压缓存被清除。
