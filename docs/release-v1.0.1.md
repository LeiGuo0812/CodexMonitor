# CodexMonitor v1.0.1

## 右键菜单

- 托盘图标和任务栏文字右键菜单均新增 **开机启动** 和 **清除缓存**，与 **退出** 独立。
- 开机启动使用勾选表示已注册，点击即保存生效；不会顺带保存尚未确认的外观编辑，关闭设置窗口也不会撤销已确认的菜单操作。
- 清除缓存后保持运行，通过托盘提示结果；清理期间菜单项暂时禁用，避免重复执行。当前运行库在正常退出后清理，保留设置与 Codex 登录信息。
- 原设置页入口保留，并共用清理逻辑。

## 下载

`CodexMonitor-v1.0.1-win-x64.exe` 是 Windows 11 x64 自包含单文件版，下载后双击运行。程序目录不释放附加文件；运行时仍使用系统缓存。`SHA256SUMS.txt` 用于校验，无需一起运行。

## 验证与资源评估

76 项回归测试通过，Release 构建无警告、无错误；真实额度刷新、菜单状态、启动项开关、缓存清理和既有 UI 自检通过。

新增可复现的资源采样脚本，统计主程序及其查询子进程，覆盖后台、详情打开、连续刷新与关闭详情后的状态。实测结果及边界见 [资源占用评估](https://github.com/LeiGuo0812/CodexMonitor/blob/v1.0.1/docs/resource-assessment-v1.0.1.md)。

本机主程序工作集平均：首次后台约 157 MiB、详情打开约 170 MiB、连续刷新约 180 MiB；使用后后台约 215 MiB。尾段两分钟私有提交量基本稳定，但未回到初始状态，不能宣称已排除长时间内存泄漏。工作集包含共享页，不等于独占物理内存。

当前主要实测 175% 缩放；多显示器、100% / 125% 缩放与长时间稳定性仍需进一步验证。发行包未进行代码签名。
