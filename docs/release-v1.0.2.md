# CodexMonitor v1.0.2

## 可设置的刷新频率

- **默认保持 1 分钟**。右键托盘图标或任务栏文字 → **外观与位置** → **数据刷新**，可输入 **0.5–60 分钟**，支持小数并换算为整秒。
- 保存后重新计算当前后台等待时间，无需重启；取消或关闭设置不改变已保存频率。已有自定义值保留。
- 倒计时继续每秒本地更新，手动刷新及打开详情仍立即查询。失败退避不会比用户设定的间隔更频繁。
- 输入框拒绝空值、非数字和越界值；保留既有右键缓存清理、开机启动及视觉效果。

## 设置窗口标题栏

- 修复“外观与位置”窗口中标题栏与主体色调不一致的问题：将内容延伸到标题栏，关闭、最小化等按钮区域与主体共用同一层磨砂背景。
- 标题栏正常与失焦状态均使用透明底色，按钮文字随主题变化；保留原生窗口按钮与顶部拖动区域。

## 内存分析

补充 v1.0.1 运行时计数器与源码分析：诊断阶段主程序工作集约 240 MiB，托管堆近似 32–33 MiB，二者口径不同。重复样式读取、画刷分配和详情卡片重建存在优化空间；尚不能据此确认或排除长期泄漏。

延长刷新间隔减少查询子进程启动频率及时间平均开销，不能消除 WinUI / .NET 常驻内存。本次未实施内存架构改写，也不宣称已降低内存。实测数据、方法、限制和优化顺序见 [内存分析报告](https://github.com/LeiGuo0812/CodexMonitor/blob/v1.0.2/docs/memory-analysis-v1.0.2.md)。
