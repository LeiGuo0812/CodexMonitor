# CodexMonitor v1.0.3

## 按需更新与资源复用

- 系统外观对象和配色缓存复用；系统变化通知触发更新，15 秒校验补漏。
- 数字条合并定时器；文字变化才排版，颜色变化才创建画刷，全屏隐藏时暂停文字更新。
- 详情卡片复用控件，仅增删必要的行；内容不变的刷新只更新忙碌状态。卡片有效期与其他额度倒计时在本地按需更新。
- 详情最小化暂停界面时钟和内容更新，恢复时应用最新快照；关闭后解除订阅并释放动态行与动画引用。
- 设置预览、托盘提示避免无变化的重复更新；任务栏扫描复用缓冲区；移除额度 JSON 的二次解析与 stderr 的逐行字符串分配。
- 默认刷新间隔仍为 **1 分钟**，可修改；保留任务栏交互、磨砂标题栏与首次进度动画。

## 实测结果与限制

102 项测试及单文件运行自检通过。100 次不变输入更新后画刷引用保持相同，新增文字测量与系统外观读取均为 0。

同机各一轮对照：后台主程序平均工作集 154.65 → 150.40 MiB；连续刷新主程序 CPU 0.594% → 0.184%；后台短时托管分配速率约 58.88 → 14.78 KiB/s。

**常驻内存没有全面下降**：打开并关闭详情后的工作集在本轮为 188.72 → 205.69 MiB，私有提交量为 111.38 → 120.37 MiB。WinUI / .NET 仍常驻；没有使用强制 GC 或工作集裁剪。测量受运行环境、采样及框架资源状态影响，完整正反结果与边界见 [资源优化报告](https://github.com/LeiGuo0812/CodexMonitor/blob/v1.0.3/docs/resource-optimization-v1.0.3.md)。
