# 验证说明

## 保留的必要检查

- 核心回归测试：额度窗口选择、字段缺失、失败与账户切换、数值范围、倒计时、卡片独立性、只读协议处理、拖动与双击判定。
- 可选运行自检：在真实 WinUI 调度器中打开/关闭设置、执行 72 次主题与细节修改、取消恢复、查询真实额度、检查宽窄布局、任务栏贴边、悬停动画、原生透明层和托盘图标。
- 自检报告只包含状态、布局和错误信息，不包含账号身份、凭据或额度值。输出 .artifacts/runtime-verification.json，不纳入 Git 或 Release。

运行命令见仓库 README。自检会短暂显示程序窗口并调用只读 Codex 接口，结束后退出。

## 已完成验证

- 102 项测试通过，包含呈现缓存、倒计时分钟/小时/天边界与时钟回拨、刷新默认值与范围、已有配置保留、等待时间重算、失败退避、取消等待，以及缓存归属、改名 EXE、其他应用缓存排除、目录层级与缺失文件检查；Release 构建 0 警告、0 错误。
- Windows 11 本机真实额度刷新成功，卡片数量与详情可读取；当前账户仅返回周额度，双窗口选择由合成单元测试覆盖。
- 72 次异步主题及细节修改、设置取消恢复、详情贴边和窄布局检查通过。
- 无 5 小时窗口时显示独立不可用提示，使用等宽纵向布局；不借用周额度填充。
- 任务栏原生透明设置与背景擦除回调正常；悬停梭形主体 alpha 为 140/255，柔光层峰值分别为 32/255 和 20/255，移开恢复透明和原细线。
- 托盘 ICO 包含 10 个尺寸，PNG 帧均可解码；本机按 DPI 加载 28 像素版本并成功注册。
- 正式命名的 `CodexMonitor-v1.0.0-win-x64.exe` 从仅含 EXE 的目录启动，自检后该目录仍只有 EXE；显式指定 PRI 资源索引，支持下载后改名。
- 实时预览后保存开机启动设置，当前用户启动项正确指向外层 EXE；关闭后移除。自检恢复原始启动项和设置。
- 点击清理所调用的服务完成即时清理，当前运行库保留；正常退出后当前解压目录被清除。采用当前包哈希识别正在使用的缓存，兼容 Windows 长路径和 8.3 短路径。
- v1.0.1：从实际 Win32 菜单读取“开机启动”的勾选、“清除缓存”的存在与忙碌禁用状态，命令路由、清理结束恢复可用检查通过。托盘和文字共用该菜单。
- v1.0.1：菜单开关立即保存启动项，不保存尚未确认的外观预览；设置窗口取消后保留已通过菜单确认的启动选项。
- 资源采样使用独立脚本，记录主程序及其后代查询进程，详见 [资源评估](resource-assessment-v1.0.1.md)。
- v1.0.2：正式命名的单 EXE 通过完整运行自检。设置中的刷新间隔默认 60 秒，验证 0.5 / 60 分钟边界、越界 / 空值 / 非有限数拒绝、编辑不修改活动频率、取消恢复、保存写入配置并更新活动调度。运行检查不逐项等待所有分钟长度，剩余等待计算由核心测试覆盖。
- 新数字输入控件在首次发行自检中触发 WinUI 原生异常，已改为现有 TextBox 并显式验证数值；重新构建的最终发行文件通过上述自检。
- 内存补测使用已发布的 v1.0.1 进程，详见 [原因与优化空间](memory-analysis-v1.0.2.md)；不能当作 v1.0.2 的优化前后对照。
- v1.0.2 设置窗口标题栏：内容扩展到标题栏，全窗共用磨砂表面；72 次主题与细节修改期间检查正常 / 失焦标题栏和按钮底色透明、按钮文字跟随主题、标题拖动区存在。

## 检查边界

v1.0.4：依次设置“自动”“任务栏优先”“固定上移”，从实际 Win32 位置子菜单读取状态，确认每次只有对应选项勾选，命令映射和保存后的配置一致；完整单文件运行自检通过。

v1.0.3 新增：100 次不变输入更新后画刷引用相同、额外文字测量 0 次、额外系统外观读取 0 次；详情相同/变化数据均复用行控件，重复卡片分别保留，删除行从集合释放；最小化时计时器停止，恢复后重启。合成卡片仅在显式运行自检中使用，之后恢复真实快照，不写入设置或正常监控数据。

首次 v1.0.3 自检的资源复用检查通过，但位置检查读到最小化窗口，未作为通过结果；相同发行文件完整复测通过，详情下缘与任务栏上缘间距为 0 DIP。未据此宣称已排除所有窗口状态时序问题。

- 运行自检通过调用应用内部状态切换和读取控件/HWND 属性完成，不等同于真实鼠标全流程操作或截图像素验收。
- 当前宿主机主要实测 175% 缩放；100% / 125%、多显示器、Explorer 重启、睡眠唤醒和系统主题切换尚未逐项人工验收。
- 单 EXE 分发包含运行时自解压。只有“程序目录无附加文件”可以作为此架构的目标，不能宣称运行过程中不创建依赖缓存或配置文件。
- 验证结果记录在本文及运行报告中；Release 说明仅列出更新内容。
